
# File Organizer Roadmap

This document outlines the planned improvements and future roadmap for **File Organizer**. The current release (**v1.0.0**) provides reliable file organization by extension, duplicate filename handling, and report generation. The following items represent planned enhancements for future versions.

---

## 🚨 High Priority

These improvements focus on performance, reliability, and data safety.

* [✓] Improve duplicate filename handling for directories containing a large number of files.
* [ ] Enhance file operation error handling to provide more detailed feedback during move operations.
* [ ] Add timestamp-based report filenames to prevent overwriting previous reports.
* [ ] Improve input validation before processing target directories.

---

## 🛠️ Medium Priority

These features will improve flexibility and usability.

* [ ] Add optional recursive directory organization.
* [ ] Allow users to define custom organization rules.
* [ ] Support configurable destination folders.
* [ ] Improve generated reports with additional statistics.

---

## 💡 Low Priority

Quality-of-life improvements planned for future releases.

* [ ] Add a preview (dry-run) mode.
* [ ] Ignore hidden and system files automatically.
* [ ] Export reports in CSV format.
* [ ] Add optional colorized terminal output.

---

## 🚀 Long-Term Goals

Larger features planned for future major versions.

* [ ] Organize files using custom categories instead of extensions only.
* [ ] Monitor folders and organize new files automatically.
* [ ] Support batch processing of multiple directories.
* [ ] Add a graphical user interface (GUI).

---
